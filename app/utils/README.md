# Словарь очистки

`elements.yaml` загружается `services/cleaner.py` один раз при создании `TextCleaner`. Категории `names`, `surnames`, `patronymics`, `locations`, `streets`, `organizations`, `legal_forms`, `special` определяют тип замены. `exceptions` содержит защищённые названия Сбера.

Основу разделов имён, фамилий и отчеств составили частотные списки [sorokinpf/russian_names](https://github.com/sorokinpf/russian_names) (первые 3000 имён, 2500 фамилий и 800 отчеств); к части слов добавлены падежные формы. Это **не исчерпывающий** список персональных данных: неизвестные имена и адреса могут остаться. При добавлении слов проверяйте ложные совпадения с обычными терминами банковского диалога.

Очиститель обрабатывает каждый текст линейным проходом после структурных регулярных выражений. Поиск словоформ выполняется в хэш-словаре. Календарные даты вида `17 декабря` сохраняются, остальные цифры заменяются на `#`. Словарь не должен содержать чувствительных данных конкретных клиентов.
